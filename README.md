# Yorumcu Görüş Panosu

Takip edilen Türk ekonomi yorumcularının altın, borsa (BIST 100) ve döviz (dolar/TL)
hakkındaki haftalık görüşlerini, alıntı ve kaynak bağlantılarıyla gösteren tek sayfalık site.

Sayfa: https://webappuygulamalar.github.io/yorumcu-gorus-panosu/

- Görüşleri bilgisayarda çalışan bir yapay zekâ modeli, yorumcuların kamuya açık
  içeriklerinden çıkarır. Doğruluk henüz bağımsız olarak ölçülmedi.
- Yalnız alıntısı kaynak metinde birebir bulunan görüşler gösterilir.
- Fiyatlar haber sitelerinden derlenir; kaynaklar sayfada yazılıdır.

**Yatırım tavsiyesi değildir.**
